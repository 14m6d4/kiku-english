# Kiku English

An Anki note type for learning English by sentence mining with Yomitan and asbplayer. It is a fork of Kiku, which does the same for Japanese.

## Language

**Upstream**:
The original Kiku project (youyoumu/kiku) this repository was forked from.
_Avoid_: Kiku gốc, original, base

**Sentence mining**:
Collecting words to learn together with the real sentence they were met in.
_Avoid_: Card making, harvesting

**Expression**:
The word or phrase a note teaches, exactly as the dictionary lookup returned it.
_Avoid_: Word, term, target, vocab

**Reading**:
The IPA transcription of the Expression, including stress marks.
_Avoid_: Pronunciation, phonetics, furigana

**Sentence**:
The source sentence the Expression was mined from, with the Expression marked inside it.
_Avoid_: Context, example

**Glossary**:
Every dictionary definition captured for the Expression, grouped by dictionary.
_Avoid_: Meaning, definitions

**Main definition**:
The single definition chosen to show first, ahead of the rest of the Glossary.
_Avoid_: Primary meaning

**Card mode**:
What a note shows on its front: the Expression alone, Expression with Sentence, a click-to-reveal Sentence, the Sentence alone, or audio alone.
_Avoid_: Card type, template

**Related notes**:
Other notes connected to the current one: same Expression, same Reading (homophones), or linked by hand.
_Avoid_: Kanji web, similar cards

**Frequency**:
How common the Expression is, as a rank where a lower number means more common.
_Avoid_: Level, difficulty

**Word family**:
Words built from the same root as the Expression, such as decide, decision, decisive. Not supported yet.
_Avoid_: Derivatives, forms
